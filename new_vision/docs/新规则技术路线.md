## 2. 几何图卡识别方案对比

### 场景特征
- 10cm×10cm 白底卡，黑线图形（0.5cm粗），带10cm标准矩形外边框
- 平贴地面（透明胶带），3处固定位置
- 车载摄像头视角（斜视地面），存在透视变形
- 图卡外框4角可做**单应性矫正**（与现有IPM基础设施同源）

### 四方案对比

| 维度 | A. 传统CV | B. CNN分类 | C. 模板匹配 | D. 混合方案 |
|------|----------|-----------|------------|------------|
| **方法** | 轮廓提取→approxPolyDP→Hu矩→形状分类 | MobileNet等小CNN，TensorRT推理 | 模板多尺度+旋转遍历 | CV快速过滤分类 + CNN兜底 |
| **Nano帧率** | >100fps | ~30-50fps（TensorRT优化后） | ~50-80fps | 100fps主路径 |
| **精度预估** | 95%+（受光照/视角影响） | 98%+（数据充足时） | 90%+（需要外框矫正） | 98%+ |
| **开发工作量** | 1-2周 | 3-4周（数据采集+训练+部署） | 1周（沿用digit_reader思路） | 3-5周 |
| **资格认证友好度** | **最友好**（可解释性强，正对认证要求） | 差（黑盒难解释） | 中 | 好（以A为主讲） |
| **数据需求** | 无 | 需采集/合成训练数据 | 模板图片即可 | 少量数据 |

### 推荐：方案D（混合），认证以A为主

**理由：**
1. 2026认证明确要求"Hu矩匹配、多边形拟合"等算法逻辑说明——传统CV是认证的得分点，必须实现
2. 6种形状中圆形/正方形/十字形用CV极简单（边数/圆形度判定），五角星/菱形/三角形用Hu矩+角点数也能区分
3. 深度学习作为兜底（光照极端、透视过大时），不在认证中作为主方案
4. 单应性矫正复用现有IPM经验，把卡面矫正成正视图后分类，鲁棒性大增

### 具体识别流程（方案D）

```
1. 外框检测：找矩形轮廓（10cm外框）→ 4角点
2. 单应性矫正：4角点 → 正方形正视图（复用IPM的getPerspectiveTransform思路）
3. 主分类（CV）：
   - 圆形度检测（周长²/4πA ≈ 1）→ 圆
   - approxPolyDP角点数：4角+菱形度 → 正方形/菱形；5角 → 五角星；3角 → 三角形
   - 十字形：两个矩形交叉检测
4. 兜底（CNN）：CV置信度低时，跑MobileNet分类
5. 多帧确认（沿用qr_detector的稳定帧+冷却机制）
```

## 3. 对现有代码的影响

### 3.1 qr_detector.py 替换
- 新建 `jetson/shape_detector.py`，`update(frame)` 返回 `(action_number, dbg)` **接口保持不变**
- vision_main.py / run_real_car.py 的调用点改动最小
- 复用现有：稳定帧确认、冷却时间、白名单（1-6动作号）

### 3.2 停车状态机（最大改动点）
- `run_real_car.py` 目前每帧只发轮速，**没有**检测→动作状态机
- 新增状态：`DRIVING → SHAPE_DETECTED → STOPPING → ACTION(3s) → RESUME`
- 识别到图卡 → 停轮 → 发动作号给MCU（或本机执行）→ 3秒 → 恢复巡线
- 需要确认：动作由MCU执行还是Jetson直连舵机？

### 3.3 3处位置利用
- 起跑线前30cm：利用 start_line_z 测距开检测窗口（接近时才开始检测，防误检）
- 直道中间：视觉里程（光流/虚线计数）辅助判断
- 弯道中间：检测窗口关闭（弯道形状干扰大），靠已知里程触发

### 3.4 巡线冲突处理
- 图卡是白底黑框，贴在赛道**内侧**（不在巡线黑线上）→ 对巡线干扰小
- 检测到图卡后停车3秒，巡线PID保持（或冻结），恢复时无跳变

## 4. 硬件分工建议

| 硬件 | 职责 |
|------|------|
| **GPU（桌面）** | CNN训练/数据增强/仿真调参/离线测试 |
| **CPU（桌面）** | 算法开发、Webots仿真、数据集生成 |
| **Jetson Nano** | 实时推理（CV主路径 >100fps，CNN兜底 TensorRT 30-50fps） |
| **USB Cam** | 720p MJPEG@30fps 足够（10cm卡在30-80cm距离约90-240px，够用，无需1080p） |

**图卡识别分工**：CV主分类跑在Nano（轻量实时），CNN兜底也跑Nano（TensorRT量化），GPU只负责离线训练——比赛时GPU/CPU不上车。
